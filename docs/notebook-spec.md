Notebook Specification

Applies to:

- workshop-clustering-Mushrooms.ipynb
- workshop-clustering-creditcard.ipynb

Both notebooks must follow the same philosophy.

Required structure

1. Introduction
2. Business / Academic objective
3. Dataset description
4. Data loading
5. Exploratory Data Analysis
6. Data quality assessment
7. Data preprocessing
8. Dimensionality reduction
9. Clustering algorithms
10. Validation
11. Anomaly detection
12. Conclusions
13. Key takeaways

Each major section must contain:

• Markdown explaining the objective
• Code
• Interpretation
• Business or academic conclusion
